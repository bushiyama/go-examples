# Supermarket Coupon
実行時間制限: 2 sec / メモリ制限: 1024 MB

高橋君はスーパーマーケットで $N$ 個の品物を買おうとしています。  
$i$ 番目の品物の価格は $P_i$ 円です。  
高橋君は「1つの品物の価格を半額（小数点以下切り捨て）にする」という割引券をちょうど $1$ 枚持っています。  
高橋君がこの割引券を最適な品物に使ったとき、支払う合計金額の最小値を求めてください。  

制約:
- $1 \leq N \leq 10^5$
- $1 \leq P_i \leq 10^9$
- 入力はすべて整数である

入力:
- とくに問いません。ロジックを実装してください。
  - 標準入力でもOK
  - ファイル入力でもOK
  - コマンドライン引数でもOK
  - テストケースのみでもOK

出力:
- 支払う合計金額の最小値を整数で出力せよ。

## 入力例
### 1
高橋君は割引券を $400$ 円の品物に使います。すると価格は $200$ 円になり、合計金額は $200 + 200 + 300 = 700$ 円となります。
```
3
200 400 300

-> 700
```

### 2
割引券を $12$ 円の品物に使います。半額にして切り捨てるため、$6$ 円になります。合計金額は $9 + 10 + 11 + 6 = 36$ 円となります。
```
4
9 10 11 12

-> 36
```

### 3
```
5
1000000000 1000000000 1000000000 1000000000 1000000000

-> 4500000000
```
